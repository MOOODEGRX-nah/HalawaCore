HalawaCore 0.4.0 — العربية

هذه نسخة محمولة؛ لا تحتاج تثبيت بايثون أو كتابة أوامر.
Windows 10 / 11 بمعمارية x64: فك ضغط الملف وافتح HalawaCore.exe.
Linux بمعمارية x64: فك الضغط وافتح HalawaCore من مدير الملفات. إذا طُلب إذن التنفيذ، راجع مصدر الملف ثم اسمح به. لا تشغّل البرنامج بصلاحيات الجذر. تتطلب النسخة المنشورة glibc 2.35 أو أحدث.

إذا تعذّر فتح المتصفح، يطبع البرنامج رابط الواجهة المحلية في الطرفية ويستمر في العمل.
من الطرفية داخل مجلد الملف التنفيذي يمكنك تشغيله يدويًا:
./HalawaCore --no-browser
انسخ الرابط المطبوع إلى المتصفح، واترك الطرفية مفتوحة.

تفتح الواجهة المحلية تلقائيًا في المتصفح. اختر العربية أو الإنجليزية من محدد اللغة، ويُحفظ الاختيار محليًا.
ابدأ بلوحة التحكم وخريطة الأنوية في وضع القراءة فقط. اختر العملية الفعلية وسجّل قياسًا أساسيًا قبل التجربة.
افتح المساعدة والدليل تحت الإعدادات، أو اضغط علامة ؟ بجانب الأقسام لشرحها. يتوفر دليل بداية يمكن فتحه مجددًا.
أي تعديل لتوزيع الأنوية يحتاج تفعيل التجارب ومعاينة المهام المتأثرة والتأكيد. لا يوجد تحسن أداء مضمون.
أوقف التسجيل واستعد جميع التجارب قبل الضغط على إغلاق HalawaCore. إغلاق التبويب وحده لا يوقف الخادم المحلي.

دعم Windows أولي: الأنظمة متعددة مجموعات المعالجات والمهام ذات CPU Sets الصريحة تبقى للقراءة فقط.
معلومات X3D والأنوية المفضلة تظهر عند كشف النظام لها؛ البيانات الناقصة تبقى غير مؤكدة.
راجع تقرير verification.json المرفق. اختبارات خوادم Windows لا تمثل تحققًا على عتاد Windows 10/11 فعلي، واختبارات X3D تستخدم بيانات اصطناعية.

English

HalawaCore 0.4.0 — portable desktop application

No Python installation or terminal commands are needed for this executable release.

Windows 10 / 11 x64:
Extract the ZIP. Open HalawaCore.exe. Your browser opens the local interface automatically.

Linux x64:
Extract the tar.gz archive. Open the HalawaCore executable in your file manager.
If your desktop asks whether to allow execution, review that the file is from this project's release.
Do not use sudo. Native GitHub Actions Linux releases target glibc 2.35+.
Locally built Linux binaries may require the builder's newer glibc version; check release notes.

If automatic browser launch fails, the app prints its local URL and remains running.
From a terminal inside the extracted executable folder, use:
./HalawaCore --no-browser
Copy the printed URL into your browser and keep the terminal open.

Choose Arabic or English from the language selector; the app saves your choice locally.
Open Help & Guide below Settings or use the ? buttons beside sections.
The welcome guide can be reopened from Help & Guide.

The application starts in read-only mode. Analyze topology, choose a process and record a baseline.
Optional affinity changes require enabling experiments, reviewing an exact task preview, and confirming.
Stop recording and restore every experiment before using Quit HalawaCore.
Closing the browser tab alone does not stop the local backend.

Windows limits in this release:
- Multiple processor groups: topology analysis only; no affinity mutation.
- Explicit process/thread CPU Sets: target remains read-only.
- Default task means oldest surviving thread, not a claim that Windows PID equals TID.
- Linux CPPC/amd_x3d_vcache interfaces do not exist on Windows; unavailable data remains unverified.

The included verification.json reports actual tests for this binary, when available.
Windows Server CI or Wine verification is not physical Windows 10/11 hardware validation.
X3D coverage uses synthetic fixtures; no physical X3D performance claims are made.
No FPS improvements, performance gains, crash recovery or permanent child-process coverage are promised.
